# Referencias y lecturas recomendadas

Fuentes públicas independientes; no forman dependencias del agente. Consulta el contenido vigente, su licencia y versión antes de adoptar código o procedimientos.

## Playbooks públicos Forms → APEX

- [oracle-forms-migration](https://github.com/franklingjr/oracle-forms-migration): material de comunidad para revisar aplicaciones Forms y planear su destino APEX.
- [forms2apex-migration-playbook](https://github.com/silviosotelo/forms2apex-migration-playbook): playbook y plantillas para organizar migraciones de Forms a APEX.

## Documentación Oracle

- [Oracle APEX](https://docs.oracle.com/en/database/oracle/apex/): usa documentación de la versión instalada.
- [Oracle Forms](https://docs.oracle.com/en/middleware/developer-tools/forms/): usa documentación compatible con el release de origen.
- [Oracle Reports](https://docs.oracle.com/en/middleware/developer-tools/reports/): consulta el release de Reports que genera la fuente.
- [Oracle Database](https://docs.oracle.com/en/database/oracle/oracle-database/): valida SQL, PL/SQL, transacciones y seguridad para la versión destino.

## Cómo aprovechar estas fuentes

1. Lee README, licencia y versión/releases de la fuente.
2. Extrae prácticas generales; no copies ejemplos de clientes, credenciales, configuración privada ni código sin licencia compatible.
3. Verifica funciones de producto con la documentación Oracle de la versión aplicable.
4. Adapta cada recomendación a requisitos, permisos, esquema y tema APEX del destino.
5. Indica qué fuente inspiró la decisión y qué comportamiento se comprobó por separado.
